
You need to modify database.php to connect to your database.
The world name must be the same as the database name.


if used locally
$conf['db_host'] = 'localhost';
$conf['db_user'] = 'root';
$conf['db_pass'] = ''; // Leave empty for XAMPP/WAMP default
$conf['db_name'] = 'index_tw';

if using Docker
$conf['db_host'] = 'db';
$conf['db_user'] = 'db_user';
$conf['db_pass'] = 'db_pass';
$conf['db_name'] = 'index_tw';

if using db_host
$conf['db_host'] = 'db_server';
$conf['db_user'] = 'db_user';
$conf['db_pass'] = 'db_pass';
$conf['db_name'] = 'index_tw';
If I want a name like world 1, the database name should be lan_1.
If I want another name like classic 1, the database name should be lan_classic1.
